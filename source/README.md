# ZTrans 1.2.3 · 文本翻译与拾词

现在只有悬浮小窗口。双击桌面图标或按 **Ctrl + Alt + Z** 即可显示；第一次默认放在副屏右上角，以后记住屏幕、位置和尺寸。置顶默认开启，可点击左上角图钉切换；拖动顶部移动，拖动右下角调整大小。

- **拾词**：小窗显示且连续 60 秒没有翻译或操作翻译界面时，原位切换到单词便签。翻译和文档任务进行时暂停切换，完成后重新计时。点「翻译」返回原来的原文与译文，点「粘贴翻译」直接翻译剪贴板文字。
- **F1**：翻译选中文字，译文直接在副屏流式显示，小窗不会主动抢走主屏焦点。
- **原文 ▾**：展开输入区，粘贴或编辑文字后点“翻译原文”，也可按 Ctrl + Enter。
- **粘贴翻译**：使用当前剪贴板文字翻译。
- **顶部文档菜单**：导入 PDF / Word / 文本、读取网页、导出、修复断行、清空、选择翻译风格。
- **显示器按钮**：选择显示屏，或重置为副屏右上角。拔掉副屏后会回到可用屏幕。
- **齿轮按钮**：配置 Ollama / 在线 API、字体、术语和开机自启。
- **关闭按钮**：收起到托盘；托盘右键“退出 ZTrans”完全退出。登录启动仍以托盘方式运行。

下方说明中的“左侧原文 / 右侧译文”分别对应小窗展开的原文区和译文阅读区。

适用于 Windows 的本地优先翻译应用。默认连接已有的 Ollama `hy-mt1.5:7b`，也能连接自选 OpenAI 兼容 API。独立实现，不读取 TTime 的配置或账号。

## 开始使用

从源码启动或自行构建后启动 **ZTrans**。源码安装步骤见仓库根目录 README。Ollama 是独立服务，需要在本机运行；已有模型无需重新下载。

1. 粘贴文字，或将 PDF、Word 或文本文件拖入窗口。
2. 默认翻译成简体中文，可切换目标语言和“学术论文”风格。
3. 点击 **开始翻译**，或按 **Ctrl + Enter**。
4. 右侧译文可编辑、复制，或导出双语 Word / PDF / HTML、纯译文 Word / TXT。

普通 Enter 保留换行。**修复断行**会预览合并前后的内容，保留空行和列表；应用后可按 Ctrl + Z 撤销。“翻译前修复多余换行”只处理发送给模型的副本，不更改原文框。

## 快捷键与托盘

| 操作 | 快捷键 |
| --- | --- |
| 翻译其他软件中选中的文字 | F1 |
| 显示 ZTrans | Ctrl + Alt + Z |
| 翻译当前原文 | Ctrl + Enter |
| 打开文件 | Ctrl + O |
| 导出 | Ctrl + Shift + S |
| 停止当前任务 | Esc |

划词快捷键模拟一次复制；复制成功才会翻译，未选中时不会自动发送旧剪贴板。某些管理员权限窗口不能被普通权限程序复制，可手动复制再粘贴。若快捷键被占用，主窗口会提示；仍可通过窗口或托盘操作。

关闭窗口会收起到系统托盘。右键托盘 → **退出 ZTrans** 才会完全退出。已设置登录 Windows 后在托盘启动；在 **设置与隐私 → 偏好与术语** 可以关闭自启。没有开机联网检测、自动更新或后台剪贴板监听。

## 网页、PDF、Word

- **网页**：输入网址后读取正文，再点击翻译。读取网站会产生正常网页访问请求；不会读取浏览器 Cookie，不执行网页脚本。登录页、需要 JavaScript 的页面请复制正文，或导入另存的 HTML。本版是应用内正文对照阅读，不在浏览器原页面上覆盖翻译。
- **PDF**：只提取已有文本层。双栏论文、复杂表格、脚注和公式的阅读顺序可能需要人工调整。纯扫描 PDF 需先转换为含文本层的 PDF。
- **Word**：支持 `.docx` 正文和表格；`.doc` 使用本机 Microsoft Word 只读提取，禁用宏与外部链接更新。DOCX 页眉页脚、文本框、批注和图片内文字不在正文导入范围。
- **导出**：生成重新排版的可编辑双语文档，不复刻原文件的复杂排版。源文件不被覆盖。若编辑了右侧译文，双语导出按“全文原文 + 全文译文”排列。
- 输入文件上限 150 MB；网页正文上限 8 MB。长文自动分段，流式显示，可以停止。网络无响应时，停止最长等待当前 90 秒读取超时。

## 拾词单词本

词库保存在 ZTrans 安装目录的 `data\wordnote\words.json`。便签一次显示最多 5 个词，点击「释义」展开中文，点击扬声器离线朗读。超过 5 个词时每 5 分钟换一批，悬停、编辑或固定时暂停。通过「＋ 记词」和「全部单词」添加、查找、编辑、导入或导出词条。要在 ZTrans 编辑词库，请先关闭独立拾词窗口。

## 使用在线或自建 API

进入 **设置与隐私 → 翻译服务**，切换为 **在线 / 自建 API**，填写服务商基础地址、模型名和自己的 API Key。兼容标准流式 `chat/completions` 接口。可检测模型列表，也可手动填模型名。

远程服务必须为 HTTPS，并手动勾选“允许原文和匹配的术语发送到此服务地址”。更改地址会清除该确认与输入框中的旧密钥。不会从其他软件读取 API Key，也不会在本地模型失败时自动切换在线服务。

密钥可只保留在会话内，或使用 Windows 当前账户的 DPAPI 加密保存。设置、术语表保存在 `安装目录\data\settings.json`。术语每行一个，例如 `solvation = 溶剂化`；只将当前段落匹配到的条目交给模型。模型仍可能误译，科研术语、数字和公式应核对原文。

## 验证与维护

已测试本机 Ollama 实际翻译、PDF/Word 导入、双语导出和 Windows 图形界面。在线 API 协议通过模拟流测试；没有使用你的付费 API Key 发起调用。

源码在 `source` 目录；完整依赖版本在 `requirements-lock.txt`。重建需要 Python 3.12，在源码目录运行：

```powershell
.\build.ps1
```

构建脚本在独立虚拟环境中安装依赖、执行测试并打包，同时限制构建进程的 DLL 搜索路径，不修改系统环境。打包后的程序可用 `ZTrans.exe --smoke-test <测试输出目录>` 进行完整检查，该检查只使用内置示例文字，会调用本机 Ollama 并输出测试文件。

退出程序后可移除安装目录。先在设置中关闭开机自启，再删除桌面快捷方式；如需保留词库和设置，请一并保留安装目录内的 data 文件夹。不会修改 TTime 或 Ollama 安装。

接口与组件参考：[Ollama](https://docs.ollama.com/api/chat)、[HY-MT 提示词](https://github.com/Tencent-Hunyuan/HY-MT)、[Qt for Python](https://doc.qt.io/qtforpython-6/)。第三方组件许可证保留在安装目录的 `THIRD_PARTY_LICENSES` 和 `_internal` 中。
