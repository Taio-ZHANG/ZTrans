# ZTrans 数据去向说明

ZTrans 不包含用户账号、分析统计、广告、崩溃内容上传、自动更新检查或翻译中转服务器。不读取 TTime 的数据库、账号或设置。不常驻监听剪贴板。

## 哪些动作会发出请求

1. **翻译**：只请求设置里指定的模型服务。默认是 `http://127.0.0.1:11434` 的本地 Ollama。发送当前段落、目标语言、翻译要求和匹配的术语。Ollama 模式先检查模型元数据，拒绝已知云端模型或声明远程转发的模型。本机接口是否内部再转发，由运行该接口的软件决定；请使用实际安装的本地模型。
2. **检测模型**：手动点击后向指定服务获取模型列表，不发送当前原文。
3. **读取网页**：仅手动点击后访问指定网址及该站点的 HTTP 重定向，不读取浏览器 Cookie、不执行网页脚本、不会加载页面的图片/广告/脚本子资源。网站正常可见 IP、User-Agent 和所请求的网址。

远程翻译需 HTTPS 与地址对应的主动启用。翻译请求不跟随重定向，防止原文和 Authorization 被转交其他地址。所有请求忽略系统环境中的代理与 `.netrc`，本地内容不会被 ZTrans 交给环境代理。需要代理的在线服务应自行配置可信的 HTTPS 服务地址；本版没有系统代理开关。

## 本机保存什么

- 设置与术语表：`安装目录\data\settings.json`。地址、模型名与术语是普通文本。
- API Key：仅在勾选“记住密钥”时，使用 Windows DPAPI 加密并与服务地址关联。加密数据通常只能由当前 Windows 用户解密；这不能防御以同一用户权限运行的恶意程序。
- 原文和译文：不写入自动历史记录，只保留在应用内存。剪贴板复制使用系统剪贴板；Windows 自身的剪贴板历史/云同步取决于 Windows 设置。
- 用户主动导出的 Word、PDF、HTML、TXT：保存在用户选择的位置。导出先写同目录临时文件，成功后替换目标；异常退出可能留下该临时文件。
- 开机启动：当前用户 Startup 文件夹中的 `ZTrans.lnk`。
- 小窗的屏幕、相对位置、尺寸及置顶偏好：`安装目录\data\window.json`，不包含翻译内容。更新程序时如需恢复当前会话，会临时保存 Windows 当前账户加密的内容，恢复成功后立即删除。

拾词单词和备份位于安装目录的 `data\wordnote`。朗读使用 Windows 美式语音，查词使用随程序提供的本地词典。程序退出后不保留会话，但不承诺对系统分页文件、系统崩溃转储或其他软件进行安全擦除。

选择在线翻译时，所选服务商会收到翻译原文并按其规则处理；ZTrans 不代替服务商作“零留存”保证。切换到本机 Ollama 后，不会自动回退到任何在线 API。
